# 🎓 Student Management System

A simple **Student Management System** developed using **Core Java**. This console-based application allows users to manage student records by adding, displaying, searching, updating, and deleting student details. The project demonstrates the fundamentals of **Object-Oriented Programming (OOP)** and Java Collections.

---

## 🚀 Features

- ➕ Add a new student
- 📋 Display all students
- 🔍 Search a student by ID
- ✏️ Update student details
- ❌ Delete a student
- 📌 Store student age, ID, name, and branch
- 📋 Menu-driven console interface

---

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner Class

---

## 📂 Project Structure

Project.java
├── Student
├── StudentManagement
└── Project (Main Class)

---

## ▶️ How to Compile and Run

Open the terminal in the project folder and run the following commands:

javac Project.java

java Project
